# AI-Based Customer Spending Prediction

## Project Overview
This project uses Machine Learning to predict
customer spending categories as Low, Medium,
or High based on customer information.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Dataset
The dataset contains 500 customer records
with demographic and purchasing information.

## Data Analysis
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization
- Feature Engineering
- Data Preprocessing

## Machine Learning Algorithms
1. Decision Tree Classifier
2. Random Forest Classifier

## Model Evaluation
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Output
Predicts whether a customer belongs to
Low, Medium, or High spending category.

## Conclusion
This project demonstrates how Machine
Learning can help businesses understand
customer spending behaviour.
